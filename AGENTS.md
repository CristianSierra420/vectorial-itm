# AGENTS.md

## Contexto del repositorio

- Este proyecto es una guía de estudio estática para la asignatura de Geometría Vectorial y Analítica del ITM.
- La aplicación principal está contenida en un único archivo HTML: `Vectorial ITM — Guía de estudio.html`.
- El sitio no usa build tools ni dependencias de Node; se abre directamente en el navegador.
- El contenido y la interfaz están orientados a español, con terminología académica del curso y una experiencia tipo dashboard de estudio.

## Convenciones clave

- Mantener el idioma en español y la nomenclatura del curso: parcial, guía, práctica, simulacro, examen ITM.
- Priorizar cambios pequeños y dirigidos. No introducir frameworks, bundlers ni complejidad innecesaria.
- Si se modifica el HTML, conservar la estructura de navegación por pestañas y la coherencia visual del tema oscuro/claro.
- Los ejercicios, ejemplos y soluciones deben seguir el estilo del proyecto: referencias a fuente, etiquetas claras y explicación paso a paso.
- Cuando se agreguen contenidos académicos, mantenérselos consistentes con el material de clase y con la marca de “no oficial” cuando aplique.

## Cómo trabajar en este proyecto

1. Edita el archivo HTML principal para contenido y lógica, y añade CSS/JS embebidos solo si es necesario.
2. Mantén la experiencia de usuario sin backend y sin instalación previa.
3. Valida visualmente abriendo el archivo en el navegador y comprobando:
   - navegación entre secciones,
   - preguntas del quiz,
   - simulacros y respuestas revelables,
   - tema claro/oscuro,
   - examen y formularios.
4. Si agregas nuevos ejercicios o temas, respeta el mismo patrón de estructura y estilo del resto del sitio.

## Reglas para IA

- No conviertas este proyecto en una app con framework ni en un proyecto de build.
- No elimines el contenido académico ni la trazabilidad de fuentes.
- Evita cambios de diseño que rompan la legibilidad o la navegación de la página.
- Si el contenido es nuevo, prioriza claridad didáctica y precisión matemática sobre adornos visuales.

## Resultado esperado

La aplicación debe seguir funcionando como una guía de estudio didáctica, navegable, legible y de acceso inmediato para estudiantes del ITM.
